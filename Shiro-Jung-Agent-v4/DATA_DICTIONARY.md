# Data Dictionary — เมนูและหลักฐานร้าน

ชุดข้อมูล [sushiro_menu_dataset.csv](sushiro_menu_dataset.csv) มี42รายการ รวม B005 น้ำเปล่า20บาทที่ผู้ใช้ระบุ ยังไม่ยืนยันราคาปัจจุบันหรือส่วนผสมกับร้าน แอปอ่าน SQLite ที่ `data/menu.sqlite3`; CSV เป็น seed สำหรับสร้าง/นำเข้า ไม่เก็บ Secrets หรือประวัติสนทนาในฐานข้อมูลนี้

## โครงสร้างและการนำเข้า

ตาราง `menu` ใช้ `item_id` เป็น primary key; `metadata` เก็บชื่อไฟล์, SHA256, วันที่ import และแหล่งเกณฑ์ allergen ที่อ้างอิง Import validation ทำก่อนเขียน และใช้ transaction เพื่อรักษา catalogเดิมเมื่อข้อมูลไม่ผ่าน Import เป็น replace ไม่ใช่ merge

| คอลัมน์/กลุ่ม | ความหมาย |
|---|---|
| item_id | ID ไม่ซ้ำและไม่ว่าง |
| name_th / name_en | ชื่อไทย/อังกฤษ |
| category / plate_color | หมวดเมนู/สีจานจาก dataset |
| price_baht | ราคาต่อหน่วยบาท ไม่ติดลบ ทศนิยมสูงสุด2ตำแหน่ง |
| description_th / keywords | คำบรรยายและคำค้น; keywordsคั่นด้วย `;` |
| allergen_tags | แท็กที่รายงานในชุดข้อมูล คั่นด้วย `;`; ไม่ได้หมายความว่าร้านยืนยัน สูตรเก่าที่ใช้ allergens_verified ยัง importได้ |
| dietary_tags / dietary_status | exact tags เช่น raw/cooked/pork/beef/chicken; reviewed_dataset คือทบทวนชุดข้อมูล ไม่ใช่ร้านยืนยัน |
| source_url / price_status | แหล่งหลักฐานราคา และ confirmed/unverified |
| allergen_status | unknown / team_reviewed / confirmed |
| allergen_source_url | หลักฐานส่วนผสมรายเมนู ไม่ใช่เพียงลิงก์กฎหมายทั่วไป |
| checked_at | วันที่ตรวจ แนะนำ ISO8601; เว้นว่างเมื่อยังไม่ตรวจ |
| allergen_review_reason / allergen_reviewed_by | เหตุผล/แหล่งที่ทีมตรวจ และผู้ตรวจจริง จำเป็นเมื่อ team_reviewed; CSVเดิมไม่มีคอลัมน์นี้จะเติมค่าว่าง |
| allergen_display_th | ชื่อแสดงภาษาไทยจาก canonical tags |
| thai_allergen_10_unverified | กลุ่มสาร10กลุ่มที่อาจเกี่ยวข้องตาม tags ไม่ใช่ใบรับรองส่วนผสม |
| thai_allergen_gluten/crustacean/egg/fish/peanut/soy/milk/tree_nuts/sulphites/molluscs | 10คอลัมน์ possible/unknown ที่ runtimeคำนวณใหม่จาก canonical tags |
| thai_law_reference | เกณฑ์ฉลากบรรจุภัณฑ์ที่อ้างจากข้อมูลผู้ใช้ ไม่ใช่หลักฐานสูตรร้าน |
| mapping_audit_note / recommended_thai_allergen_10_unverified | บันทึกทบทวนและข้อเสนอชื่อกลุ่มจาก CSV เก็บเพื่อตรวจย้อนกลับ ไม่ใช้ลบ tags ใน runtime |

ตัว importerตรวจว่ามี metadataที่จำเป็น แต่ไม่สามารถพิสูจน์ URL/ผู้กรอก/สูตรแทนผู้ตรวจ ต้องไม่ใช้ข้อมูลสมมติจาก testsเป็นหลักฐานของร้าน

เกณฑ์ intake งบเต็มขั้นต่ำ100บาทต่อคนเป็นนโยบายผลิตภัณฑ์ ไม่ได้เปลี่ยนราคา/สถานะหลักฐานของเมนู และไม่รับประกันความอิ่ม การตรวจรับข้อมูลกับการตรวจส่วนผสมของร้านเป็นคนละเรื่อง

## สถานะหลักฐาน

| สถานะ | เงื่อนไขและผลต่อระบบ |
|---|---|
| price unverified | ค่าเริ่มต้น42/42รายการ ยังไม่ยืนยันราคาปัจจุบัน |
| price confirmed | ต้องมี source_url และ checked_at; ทีมต้องตรวจภาพป้าย/ราคา สาขา และวันที่จริง |
| allergen unknown | ค่าเริ่มต้น42/42รายการ ไม่มีหลักฐานยืนยันสูตรครบ |
| allergen team_reviewed | ต้องมี reason/reviewer/date ที่ตรวจจริง แต่ร้านยังไม่ยืนยัน **ไม่ปลด strict** |
| allergen confirmed | ต้องมี allergen_source_url และ checked_at ของหลักฐานรายเมนูจากร้าน/ผู้ผลิต ยังไม่รับประกันการปนเปื้อนข้าม |

`strict` สำหรับผู้แพ้ใช้เฉพาะ confirmed ที่ไม่ชน tags ทั้ง unknownและteam_reviewedยังปิดกั้นการแนะนำสำหรับสั่งจริง ชุดจำลองต้องยินยอมเองและคงคำเตือน **ช่องว่าง/unknownไม่ใช่ไม่มีสาร** และการไม่มีคำตอบจากร้านไม่อนุญาตให้ลบแท็กเสี่ยงหรือเปลี่ยนconfirmedเอง

## ทะเบียน10กลุ่มและข้อจำกัดเพิ่มเติม

ทะเบียนใน [regulatory_allergens.py](sushi_budgeteer/regulatory_allergens.py) อ้างประกาศ450พ.ศ.2567ข้อ5(6)ตามข้อมูลที่ผู้ใช้ให้ เป็นการจัดกลุ่มฉลากอาหารบรรจุภัณฑ์ ไม่ใช่การตรวจสูตรอาหารร้าน:

| Tag | กลุ่ม |
|---|---|
| gluten | ธัญพืชที่มีกลูเตนและผลิตภัณฑ์ |
| crustacean | สัตว์น้ำเปลือกแข็งและผลิตภัณฑ์ |
| egg | ไข่และผลิตภัณฑ์ |
| fish | ปลาและผลิตภัณฑ์ |
| peanut | ถั่วลิสงและผลิตภัณฑ์ |
| soy | ถั่วเหลืองและผลิตภัณฑ์ |
| milk | นมและผลิตภัณฑ์ รวมแลคโตส |
| tree_nuts | ถั่วเปลือกแข็งและผลิตภัณฑ์ |
| sulphites | ซัลไฟต์ตั้งแต่10มก./กก.; ไม่มีผลวิเคราะห์ปริมาณรายเมนูในชุดนี้ |
| molluscs | หอย/หมึกและผลิตภัณฑ์ |

`possible` คือมี tagที่ควรพิจารณาแต่สูตร/ปริมาณ/การปนเปื้อนยังไม่ยืนยัน; `unknown` คือไม่มีข้อมูล ไม่ได้ใช้ค่า absent งา/หมู/วัว/ไก่/seafood/echinoderm เป็นข้อจำกัดเพิ่มเติมนอกทะเบียน10กลุ่มนี้

S007 หอยเม่นเป็น echinoderm ไม่ใช่ molluscs; S014เพิ่มmilkจากเนย และ R001เพิ่มfishจากปูอัดแบบ possible โดยคงแท็กซอสเดิม การทบทวนจากคำบรรยายไม่ทำให้เป็น confirmed

การแพ้สัตว์บกใช้ `ingredient_allergens()` รวมแท็กแพ้เดิมกับ pork/beef/chickenจาก dietary_tags เพื่อกรองอย่างระวัง คำกว้าง “เนื้อ” ต้องให้ผู้ใช้เลือกชนิดก่อน และยังเลือกปลา/อาหารทะเลได้ตามข้อจำกัดอื่น ข้อห้ามใช้ exact tags/substring ที่ตรงตัว ส่วน fuzzy searchใช้สำหรับค้นหา/ความชอบ ไม่ใช้แทนหลักฐานการแพ้

## แผนยืนยันกับร้าน (ยังไม่ได้ส่ง/ยังไม่มีคำตอบ)

ส่วนนี้รวมร่างขอข้อมูลไว้ในเอกสารเดียว ไม่ใช่หลักฐานว่าร้านตอบแล้ว:

> เรียน Sushiro Thailand กลุ่มนักศึกษาขอข้อมูลส่วนผสมและสารก่อภูมิแพ้10กลุ่มของ15เมนูด้านล่าง รวมซอส ท็อปปิง น้ำหมัก และข้อมูลอุปกรณ์ร่วม/การปนเปื้อนข้าม ขอแยกรายการที่ยืนยันได้กับข้อมูลที่ยังไม่มี และระบุขอบเขตสาขา/วันที่หรือเอกสารอ้างอิงที่นำไปใช้ได้ ขอบคุณครับ/ค่ะ

รายการสำหรับสอบถาม: S001–S015 ตามชื่อปัจจุบันใน CSV ทีมต้องตรวจชื่อที่ตรงกับเมนูสาขาจริงก่อนส่ง รักษาคำตอบต้นฉบับไว้ ไม่ตีความรายการที่ร้านไม่กล่าวถึงว่าไม่มีสารนั้น

ราคา: ถ่ายภาพป้าย/สีจาน พร้อมชื่อสาขา วันที่ และเงื่อนไขโปรโมชัน/ภาษี/ค่าบริการ จับคู่รหัสเมนูกับหลักฐาน เก็บลิงก์หรือที่อ้างอิงภาพและผู้ตรวจไว้ก่อนตั้งconfirmed

สร้างแบบฟอร์ม42เมนูสำหรับกรอกหลักฐานในเครื่อง:

```bash
python scripts/catalog_audit.py --checklist artifacts/generated/menu-evidence-checklist.csv
```

ไฟล์ checklistเป็นแบบฟอร์ม ไม่ใช่การรับรอง หากไม่มีคำตอบร้านและทีมตรวจข้อมูลจริงแล้วจึงใช้ team_reviewedพร้อมเหตุผล/ผู้ตรวจ/วันที่; ไม่ตั้งอัตโนมัติเพียงเพราะร้านไม่ตอบ การใช้ชุดจำลองไม่ทดแทนการตรวจส่วนผสมกับร้าน โดยเฉพาะกรณีแพ้รุนแรง
