# แบบขอข้อมูลจากร้านและเกณฑ์บันทึกหลักฐาน

เอกสารนี้เป็นร่างสำหรับทีมส่งเอง ยังไม่ได้ส่งข้อความถึงร้านและยังไม่มีคำตอบจากร้านในชุดหลักฐานนี้ ไม่ใช้การไม่มีคำตอบเป็นหลักฐานว่าไม่มีสารก่อภูมิแพ้

## ร่างคำถามสำหรับช่องทางลูกค้าทางการ Sushiro Thailand

เรียนทีม Sushiro Thailand กลุ่มนักศึกษากำลังจัดทำโครงงานช่วยวางแผนมื้ออาหาร ขอข้อมูลส่วนผสมและสารก่อภูมิแพ้รายเมนูตามรายการด้านล่าง โดยรวมซอส ท็อปปิง และน้ำหมักด้วยครับ/ค่ะ ขอทราบว่ามีข้อมูลใดเกี่ยวกับความเสี่ยงจากการใช้ภาชนะ/อุปกรณ์ร่วมกัน และสามารถอ้างอิงเอกสารหรือคำตอบนี้สำหรับสาขาใด วันที่ใดได้บ้าง

ขอข้อมูลกลุ่มสารก่อภูมิแพ้: ธัญพืชมีกลูเตน สัตว์น้ำเปลือกแข็ง ไข่ ปลา ถั่วลิสง ถั่วเหลือง นม ถั่วเปลือกแข็ง ซัลไฟต์ และหอย/หมึก รวมถึงส่วนผสมหมู/วัว/ไก่สำหรับข้อจำกัดเพิ่มเติมของผู้ใช้ ขอแยกข้อมูลที่ยืนยันได้กับข้อมูลที่ร้านไม่มีรายละเอียด กรุณาอย่าตีความรายการที่ไม่กล่าวถึงว่าไม่มีสารนั้น

## ราคา

บันทึกภาพป้ายราคาและสีจานที่สาขาจริง พร้อมชื่อสาขา วันที่ถ่าย ภาษี/ค่าบริการ/โปรโมชันที่เกี่ยวข้อง จับคู่หลักฐานกับรหัสเมนูให้ตรวจสอบได้ ใส่ที่เก็บภาพใน `source_url` และวันที่ใน `checked_at` จึงเปลี่ยน `price_status=confirmed` โดยผู้ตรวจ ไม่อนุมานราคาปัจจุบันจาก CSV เดิม

## สถานะสารก่อภูมิแพ้

- `unknown`: ยังไม่มีการตรวจที่มีหลักฐานเพียงพอ ค่าเริ่มต้นของทั้ง 42 เมนูยังเป็นสถานะนี้
- `team_reviewed`: ทีมตรวจข้อมูลรายเมนูแล้ว แต่ร้านยังไม่ได้ยืนยัน ต้องกรอก `allergen_review_reason`, `allergen_reviewed_by`, `checked_at` พร้อมเหตุผล/แหล่งที่ตรวจและสถานะการติดต่อจริง ไม่ตั้งค่านี้อัตโนมัติเพียงเพราะร้านยังไม่ตอบ
- `confirmed`: มีคำตอบ/เอกสารของร้านรายเมนูที่อ้างอิงได้ ต้องกรอก `allergen_source_url`, `checked_at` และรักษาหลักฐานการตอบไว้ การบันทึกนี้ไม่รับประกันการปนเปื้อนข้าม

Strict ยอมรับสารก่อภูมิแพ้เฉพาะ `confirmed` เท่านั้น: `team_reviewed` และ `unknown` ไม่ปลดล็อกการแนะนำสำหรับสั่งจริง ผู้ใช้ต้องยินยอมดูชุดจำลองเองตามเดิม การไม่มีคำตอบไม่อนุญาตให้ลบแท็กส่วนผสมที่อาจมีออก

ไฟล์ CSV checklist ที่จัดส่งแยกเป็นแบบฟอร์มบันทึกการตรวจ ไม่ใช่หลักฐานที่ยืนยันแล้ว การนำเข้าต้องเพิ่มคอลัมน์ใหม่ลง dataset ตาม DATA_DICTIONARY และสำรอง SQLite ก่อนรัน import
